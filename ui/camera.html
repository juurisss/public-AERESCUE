Share this laptop’s camera

Send video to AERESCUE while this page stays open. Your microphone is never requested. Frames are processed live, not saved by this sharing endpoint.

Allow camera access, check the preview, then start sharing.

On the AERESCUE console, select the matching Browser camera slot for Camera A or B. Select two different sources, mark the target in both feeds, then start tracking.

Connecting from another laptop

Use the same Wi-Fi or hotspot. Open https://SERVER-IP:5443/camera using the server laptop’s network address. The server must be started with a certificate trusted by this laptop. Plain HTTP network addresses cannot request browser camera permission.

If your school network blocks connections between laptops, use an allowed hotspot. See docs/REMOTE_CAMERAS.md on the server for HTTPS setup.
